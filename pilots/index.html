Two founding pilots.

Certanum is looking for two founding pilot partners, in financial services or pharmaceuticals, to answer one question with evidence:

When an AI system produces a number that matters, can you prove how it was produced?

01The question

An AI system can be authorised to act. A tool can execute correctly. None of these establishes where a consequential figure came from.

For the figures in scope, each pilot establishes whether the source values and the computation behind each figure can be evidenced; whether the result can be independently reproduced; and whether the system declines to release a figure when the evidence required to support it is unavailable.

02Scope

One workflow. One class of consequential figure. Success criteria agreed before we begin.

This is not a broad AI transformation project. It is a deliberately bounded technical pilot.

Financial services

03Terms

Certanum funds the initial pilot work.

In return we look for a serious technical partner, a named internal sponsor and, where possible, permission to publish an anonymised methodology and findings.

Where the pilot meets its agreed criteria, we agree a route to a commercial phase. The scope, success criteria, data handling and what each party contributes are set out in writing before any work begins.
