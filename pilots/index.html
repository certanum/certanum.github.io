Two founding pilots.

Certanum is looking for two founding pilot partners, in financial services or pharmaceuticals, to answer one question with evidence:

When an AI system produces a number that matters, can you prove how it was produced?

The question

An AI system can be authorised to act. A tool can execute correctly. An API call can succeed. None of these establishes where a consequential figure came from.

For the figures in scope, each pilot establishes three things: whether the source values and the computation behind each figure can be evidenced; whether the result can be independently reproduced; and whether the system declines to release a figure when the evidence required to support it is unavailable.

Scope

One workflow. One class of consequential figure. Success criteria agreed before we begin.

This is not a broad AI transformation project. It is a deliberately bounded technical pilot.

Financial services

A consequential numerical workflow in areas such as payments, lending, risk, financial reporting or agentic finance.

Pharmaceuticals

A consequential numerical workflow involving a derived clinical, scientific or operational value.

Terms

Certanum funds the initial pilot work.

In return we look for a serious technical partner, a named internal sponsor and, where possible, permission to publish an anonymised methodology and findings.

Where the pilot meets its agreed criteria, we agree a route to a commercial phase. The scope, success criteria, data handling and what each party contributes are set out in writing before any work begins.

Standard and system

AP-1 is open. Certanum is not.

AP-1, the Admissibility Protocol, measures whether a consequential figure produced by an AI system was computed, traceable, reproducible and refusable. It is authored by Marcus Rupp and published by ZORRZ Financial Inc. under CC BY 4.0, and can be examined independently of Certanum at numericaladmissibility.org.

Certanum is the proprietary architecture built to satisfy it. Certanum does not control the standard and holds no certification, registry or accreditation role. A founding pilot is not an independent evaluation of AP-1.
